## Biggest challenge
The API service was the greatest challenge. I had trouble figuring out how to jam the api key in considering all the examples were with public API's. Then actually getting it to display the Stock object was painful due to the fact that by default the UI doesn't register any changes in objects. 
I eventually figured it out once I got out of my head but considering I couldn't exactly not get this done considering it was a lynchpin, and I had a separate project due on the same day that I had to ditch added to the stress and thus the slowness of progress. 

## Most valuable thing I learned
While having an achievable, and doable project is good, if the scope of the project isn't expandable it can lead to everyone twiddling their thumbs while not making something as good as it could be. Next project I'll stick with a project that can be accomplished early, but has enough stretch goals to be beyond basic
